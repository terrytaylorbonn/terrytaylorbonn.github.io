<img src="/assets/D3/P5.06.png" alt="xxx" width="55%" style="border: 1px solid #999;">

### NOTE: It will:

- live-monitor `[Ttbonn] Patient`;
- trigger when a Patient newly enters the object set;
- invoke `D3 AIP Logic 555` once for each new Patient;
- automatically execute the returned Action edits.

### NOTE: Before clicking **Create automation**, verify only:

1. The old Automation is paused, to avoid duplicate processing.
2. The static Clinical Trial input is the intended trial.
3. The **December 1, 2026** expiration date is intentional.
4. **User scoped security** is appropriate. Use project-scoped security only if teammates need to see the execution events.

### NOTE: **The new Automation is active and waiting for its first event.**

`No previous events` is expected until a new Patient is added. To test:

1. Add a new Patient through the UI.
2. Wait up to approximately one minute.
3. Check the Automation’s event history.
4. Refresh the Patient display and verify the eligibility decision/reasoning.

The two `Unknown object type` warnings belong to unrelated Automations and do not affect `D3 AIP Logic 555 automation`.
